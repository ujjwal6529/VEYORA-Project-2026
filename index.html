Simple process

From report to follow-up

Three straightforward steps help citizens submit and follow a civic report.

01 / REPORT

Describe the issue

Choose a category, enter the location and explain what needs attention. Add a relevant photo if available.

02 / SAVE ID

Keep your tracking ID

After a successful submission, save the unique ID shown on screen so you can look up the report later.

03 / FOLLOW UP

Check the status

Use the tracking section to check the latest status made available by the platform.
